## What already works and what remains

Exact unchanged-source restoration uses retained original blobs and deterministic
view maps; a learned latent does not recover deleted formatting or comments.
The parallel host mapper additionally handles one explicit edit within retained
spans in a clean fenced candidate. Actual worker compact-edit submission,
repeated dirty-overlay editing and a complete editable/executable minified
filesystem remain open. A read-only filesystem export could later consume the
same view resolver without replacing exact execution source.

Initial Terminal preparation already defers some optional program bodies rather
than copying the full repository into the prompt. Required and nondeferred
support sources remain inline. The compact reader is optional alongside ordinary
file/search/terminal tools; a compact read can precede an exact reread. Complete
capsules/formulas can also exceed source: the retained selected obligation display
was 5,520 bytes for a 642-byte source file. Stored-byte reductions and helper
call counts therefore cannot certify a reduction in provider tokens.

## Intended indexed workflow

Use IntentIR requirements to query current source-bound CodebaseIR, lexical/vector
indexes and dependencies. Add applicable SecurityIR, UI/UX IR or LegalIR
constraints, then select small readable capsules, source spans and native checked
proof results. Keep full indexes, mapping sidecars and proof artifacts host-side.
Expand exact source or use a qualified mapped edit when needed; refresh changed
generations and invalidate dependent proof results.

DuckDB catalogs and the existing Quack owner provide bounded access. DuckLake
retains database history; source freshness, proof applicability and model-context
replacement still need supervisor contracts. Each IR retains its own family,
schema/version, decoder task, dimension/window, checkpoint and database identity.
Reuse existing assets; do not treat configured 8D/384D/768D profiles as evidence
that every family/task decoder is ready.

   discovery, expansion and repair; byte counts remain distinct from tokens.
5. Run repeated matched complete sessions with native all-attempt usage and
