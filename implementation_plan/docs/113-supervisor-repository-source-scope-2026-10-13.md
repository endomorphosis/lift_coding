## Scope and reuse boundaries

Selection uses exact sorted raw-path identities, explicit required support and
explicit program roles. Its common limit is 64 files and 1,000,000 original bytes,
counting duplicate content separately for each path. Mandatory instruction, smoke
and profile supports consume those same bounds. Unknown or unsupported selections
and overflow refuse the whole nomination. No file is silently appended or dropped.

All unselected originals remain in the frontier, with explicit exclusions for
unsafe paths, nontext sources, symlinks, gitlinks and oversized originals. Exported
observations contain metadata and false current-source, task-admission, proof,
execution, completion and omission flags. The adapter reuses the existing CAS and
cold loader without creating another database or reading a current checkout.
Cold replay verifies every retained blob; each metadata page also validates the
whole in-memory frontier. Bounded output does not establish bounded setup cost.

Existing original/compact source readers and lossless mappings remain separate
from this nomination. Lower byte counts for a view do not establish lower billed
tokens. Decoder checkpoints, embeddings, family/schema/task inventories, database
ownership and foreign worktrees are preserved by this increment.

for incompatible contracts, and the CLI option has different meanings. The next
integration should separate the older helper module, schema, option and keyword;
then reconcile the existing sessions, compiler and planning consumers with current
role-context and shared-recipe APIs. Reuse that implementation while preserving
the separate IR families, dimensions, decoder tasks and assets.

Native preparation currently signs a complete `task_profile.input_paths` inventory.
A reviewed versioned semantic/read scope must sit alongside that complete profile,
retain mandatory supports and pass the native task/allocation/current-source
owners. Typed source lookup has separate 256-path and coding-child 32-path bounds.
A historical nomination cannot broaden those channels or substitute a smaller
signed complete profile. Actual worker adoption and stale-source fencing need
qualification before matched full-session token and task-success comparisons.
