# Action-span learning improves proposals; malformed-trigger refusal remains open

The next completed CPU experiment keeps the selected trigger class readout fixed
and trains source support and action endpoints. On the same fresh authored panel,
the parent gives 28/64 exact positive proposals, linear residuals 37/64 and MLP
residuals 39/64. Raw action spans improve from 48/64 to 58/64 and 62/64. Unsupported
emissions rise from 7/64 to 11/64 and 12/64. The action improvement therefore does
not qualify a default replacement. The [preceding trigger experiment](65-trigger-modality-readout-2026-10-07.md)
and [parallel dual-bank work](65-dual-bank-wording-retention-adapter-2026-10-07.md)
remain preserved alongside this additive contribution.

Incoming main also preserves the separate [native 384D two-bank replay](https://github.com/endomorphosis/ipfs_datasets_py/blob/6791fc5d6bb58f4c074063bb01bd56071ab23c2d/docs/autoencoders/dual_bank_replay_results_20261007.md).
Its one 170-update fit reconstructs all 48/48 paragraphs and 180/180 rules on
each original, old normative and balanced TRAIN set, recovering the bank-replacement
retention regression. Previously exposed development wording remains 30/48,
below the archived control's 33/48. This used a fresh optimizer without a fresh
matched control, so it establishes TRAIN retention rather than a generalization
or speed improvement. Its seven-facet authored targets have empty qualifiers and
supply no legal-gold or Lake admission. The support/action occurrence pilot
retains a separate lineage; combining these results requires a declared latent
interface and a new matched evaluation rather than treating their scores as
interchangeable.

The [datasets implementation](https://github.com/endomorphosis/ipfs_datasets_py/blob/d93f1b79fd6f8e413010bbca506473a8f67dbe1e/docs/implementation/legal_scope_support_action_pilot_20261007.md) adds an explicit opt-in API using
the exact selected trigger parent `6e4be3...`. All 26,685 parent parameters,
including its class adapter, stay frozen. Both new arms use its 64-wide mean
states for support and token states for action endpoints. Linear has 195 new
parameters, MLP 6,339 with hidden width 32. Zero final projections preserve the
measured initial parent function. This is an equal-data/update comparison with
different parameter capacities. It reads source text and does not consume the
8D/384D/768D legal latent representations.

Both arms retain all 28 parent whole successes and gain nine/eleven, but retain
every old unsupported emission and add four/five. Ten/eleven of the updated
unsupported emissions are modal anagrams; one is an extra exception. Unsupported
means outside the declared single-rule profile, not legally false. No threshold,
selection rule or model tensor is changed after these final observations.

The frozen class/nonaction facets impose a 43/64 whole-proposal ceiling on this
cohort; another 21 rows need changes outside these new heads. The exact
gerund-agent template is `gerund_object_agent_modal_condition`: raw actions
improve 6/8→7/8→8/8 and whole proposals 4/8→5/8→6/8. Last-TRAIN diagnostics at
actual update 240 give linear/MLP actions 505/512 and 512/512, whole proposals
313/512 and 323/512, and unsupported emissions 103/512 and 107/512. These extra
forwards neither select checkpoints nor add optimizer steps.

The fresh bank has 512+512 TRAIN and 64+64 selection/final rows. All 1,280 sources
and 640 paired groups are excluded from both earlier banks together, with 2,560
sources and 1,280 groups. Declared/observed nonmodal facets, semantic heads and
declared content words are also excluded between splits and earlier banks. All
eight action lemmas now occur in every template, unlike the older evaluation
assignment. Nullable cells, corruption categories, Unicode, repeated occurrences
and caller premises have explicit ledgers. Grammar/modal aliases and corruption
permutations remain shared; construction validation is not reviewed US Code gold.

Each arm runs seed 24604, 240 AdamW calls at learning rate 0.003, zero weight decay
and clip 5. Each call encodes eight supported plus eight unsupported sources.
Support BCE uses all 16, while half the sum of action start/end CE uses the eight
positives. Across both arms this is 480 joint optimizer calls and 7,680 encoded
source presentations, including 3,840 unsupported support presentations. Action
and support counters refer to those same calls, not 960 separate steps. No class
loss or original-Adam continuation occurs. An all-negative call updates support
and leaves action gradients, weights, moments and counters idle.

Selection at 0/120/240 first excludes candidates with fewer positive emissions,
more positive learned refusals or fewer positive whole successes than measured
step zero. Eligible candidates maximize whole successes plus learned negative
refusals, then fewer unsupported emissions, more positive exactness and earlier
update. Step zero is the fallback; the floors prevent reject-all winning. They
are aggregate selection constraints, not per-case or negative-emission guarantees.
Both checkpoint choices are durable before numerical parsing of the fresh final
and two earlier retention references; all nine source-only panels are durable
before their joins. Authors had mechanically reviewed construction labels, so
the barrier does not imply an authors-blind legal evaluation.
