# Normative checkpoint replay and the remaining reconstruction gates

The selected normative Legal384/768 checkpoints now have an explicit opt-in
cached runtime. The [datasets contract](https://github.com/endomorphosis/ipfs_datasets_py/blob/6a954ecef4fa78a5e58aa4fdb070cc3d1e86fcff/docs/autoencoders/normative_legal_ir_runtime.md)
supports each exact zero/auxiliary recipe, its unchanged 32-value codec and
original cached input split. It keeps the original contextual continuation path
and the separate 8D, grouped, prose and logic-family decoder tasks distinct.
The [evidence](../../artifacts/normative-decoder-runtime-20261007/README.md)
retains source/result reviews and actual source-only replay.

This contribution includes the October 7 other-agent
[reconciliation](61-autoencoder-reconciliation-2026-10-07.md), qualifier boundary
tests and updated data proposal, already on datasets main `90c58048...` and
workspace main `9c602b3d...`. Those contributions are preserved; their source and
measurement scopes remain separate from this runtime extension.

The repeated 28 normative controls are counted once: 194 distinct cases, zero
failures/errors/skips. Weights, source vectors and RNG remain unchanged. All
selected and last-attempt checkpoint containers from the earlier public release
remain registered. The runtime requires selected role independently from the
`selected=True` header, which the last-attempt aliases also carry.

The seven-field request binds family, input dimension/role, task, exact checkpoint
bytes, versioned execution contract and training recipe. Its fifteen source pins
cover the new adapter and native registration identity helper alongside the
existing numerical closure. Preparation emits the exact ModelManager selector;
the separate catalog observation resolves it to the original saved asset. A
fresh supervisor task can retain both records and the catalog generation.
This adds an opt-in replay capability and does not activate a supervisor default.

The execution contract does not fill native schema/profile/format selectors:
those remain null. Runtime release, teacher, quality, complete IO and proof
qualification remain false. Paragraph producer provenance is caller-bound;
existing 768D historical 8192-token producer metadata is not a new encoder run.
The current decoder retains a 512-token output budget and eight-clause geometry.
No encoder, optimizer, training, Hub or database action ran during generation.
