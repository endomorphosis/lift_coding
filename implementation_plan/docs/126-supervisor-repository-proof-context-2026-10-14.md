## Scope and retained owners

`RepositoryProofContextAdapter` reuses the original session, native index,
compiler, proof-cache gate and live `HeaderProofCacheAdmission`. The host
independently reviews the complete native key, receipt identity, owner pin,
signed source manifest, task scope and generation. A worker claim or serialized
cache hit cannot replace that admission. Complete public theorem inputs, source
premises, assumptions, residual obligations and open frontiers stay mandatory;
the compiler may defer only the optional proof digest. SecurityIR residuals
remain unresolved.

The source join checks the complete signed regular-file population, including
omitted originals. The native proof repository and signed task-scope CID remain
separate from the session repository ID and source-view SHA256. A fully signed
dirty candidate is supported; Git-tree equivalence is unqualified. Closing
source and proof checks bracket callback-bearing compilation, expansion, retry
and rendering. These sequential checks provide no filesystem writer lease.
The bridge and its detached observations confer no proof, execution, mutation,
completion, omission or whole-program authority.
