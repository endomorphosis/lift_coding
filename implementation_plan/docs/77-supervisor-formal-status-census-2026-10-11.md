# Formal-status availability before supervisor context replacement

The supervisor now has an explicit census boundary for formal proof reuse.
Current Terminal preparation supplies task-bound Source384/numerical candidate
evidence and proof references, but no complete admitted native proof-owner/key
binding. The opt-in reports accepted receipt and repeated-status coverage as
unknown, rather than treating those references as accepted proofs or reporting
zero coverage. It consults no proof owner and preserves the native prompt.

`prepare_terminal_live_metadata_census(..., include_formal_status_census=True)`
returns a separately versioned owner report. Its checked Terminal task/source/
context binding is distinct from the unavailable proof binding. Source, task,
context and world drift, worktree cleanup failure and final registration failure
invalidate the escaped context observation. Default reports and runner options
remain unchanged.

A programmatic host can supply an already admitted native Doctor gate, complete
keys, independently expected key identities and a current-binding probe. The
adapter validates the entire bounded request before callbacks or filesystem
observation, fences the existing owner file identity, consults the native gate,
revalidates before render and checks visible denial state for all requested keys
after callbacks. Source/owner drift, malformed receipts and visible revocations
refuse qualification. No arbitrary database locator or owner constructor is
introduced.

Normal native lookup can write dependency, observation, refusal and equivocation
bookkeeping to its existing owner. The census reports that possibility and
suppresses opportunistic metadata-owner activation. Its native call counters
do not attest arbitrary side effects inside the host's admitted source probe.
Sequential per-key observations are not an atomic owner snapshot and cannot
replace fresh render/commit revalidation.

The positive cache admits only complete/current proved receipts with sufficient
derived assurance. Misses remain open. Diagnostics, quarantine and tombstones
retain their distinct dispositions; denied requested keys retain diagnostic
observations with null accepted coverage. Full recorded/derived verdict
populations and repeated-status coverage remain unmeasured. No observation
grants proof, replacement, omission, execution, completion or savings authority.
