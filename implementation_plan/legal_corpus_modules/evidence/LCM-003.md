```python
Promoted from ``justicedao/world_law_scrapers`` ``caselaw/de_rii/collect.py`` at
``e8169767dcb69aff9e09e27f13e7450a031d95dc``. This module does not replace
``collect_gii`` and does not change the Germany statute query route.
```

Row keys, in the order `parse` writes them: `ecli`, `jurisdiction`, `court`, `chamber`, `date`, `number`, `title`, `text`, `source_url`, `archive_name`, `is_archive`, `licence`, `retrieved_at`, `court_id`, `rii_doknr`, `doctype`, `norm`, `config`. `config` is the literal `de_bund`. ## `recap_archive_scraper`

Local contract: `ipfs_datasets_py/processors/legal_scrapers/recap_archive_scraper.py`. The file assigns no schema version string. `search_recap_documents` calls `https://www.courtlistener.com/api/rest/v3/search/`. `get_recap_document` calls `https://www.courtlistener.com/api/rest/v3/recap-documents/{document_id}/`. That merge does not make the search keys and the detail keys one declared schema.
