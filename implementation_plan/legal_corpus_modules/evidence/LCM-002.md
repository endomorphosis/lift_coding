## Empty-string rule

The module docstring:

```python
- every column is nullable in Arrow, but writers serialize missing values
  as ``""`` — NULLs are a validation failure;
```

`validate_table` gate 3 is `no NULL values anywhere (missing serializes as "")`. A NULL fails with:

```python
errors.append(f"column {name!r}: {nulls} NULL values (serialize missing as \"\")")
```

`rows_to_table` writes that rule as:

```python
v = row.get(c, "")
columns[c].append("" if v is None else str(v))
```

The docstring above that function says string columns are coerced with `str(v or "")` (never NULL). The body treats only `None` as `""` and otherwise calls `str(v)`. `PLAN.md` says writers serialize a missing value as `""` and a NULL is a validation failure. That still matches the docstring and `validate_table`.
