# Trigger readout experiment evidence

The matched CPU experiment compares the unchanged ordered source-span donor,
a global residual modality adapter, and an adapter weighted by predicted
modality endpoints. Fresh final raw classes are 19/64, 29/64 and 47/64; whole
exact emitted proposals are 11/64, 17/64 and 30/64. Each adapter ran 240 actual
updates. The earlier exposed cohort is postfit retention only: whole exactness
is 12/64, 15/64 and 29/64. Trigger gains include two previously correct whole
outputs lost. Nothing here establishes reviewed statutory fidelity.

All outputs remain occurrence proposals with zero admission masks and null
formal output. No default weights were promoted and no Lake or broader logic
family qualification was run. See the implementation report for limitations
and the next support/action-span training hypothesis.

The complete release and selected weights are pinned at
[Hugging Face revision 09ac0af19c801b53216f83c3544c8d54b763f091](https://huggingface.co/Publicus/legal-ir-autoencoder/tree/09ac0af19c801b53216f83c3544c8d54b763f091/experiments/trigger-readout-20261007/run-01).
`published-README.md` preserves the original release README exactly; the source
snapshot in `source/` predates the later retention paragraph and immutable link
in the GitHub contribution. `retention/` preserves the nine-file append exactly.
The final Git source and its review are recorded separately in `evidence/`.

`retention-manifest.json` binds every local file except itself and maps every
published file to either byte-identical retained evidence or its pinned Hub URL,
size and SHA-256. Four large files remain Hub-only: two selected checkpoint
JSONs and the two last-TRAIN prediction panels. The original manifest excludes
its own bytes; the local map binds its published bytes too. The stronger Hub
replay receipt binds its script, inputs and expected complete prediction panels.

The protocols and helpers preserve historical absolute paths for provenance.
Portable reruns must deliberately rebind and review those paths; the authored
labels and construction helpers are not legal reference data. Hosted CI
availability is recorded separately from successful local validation.
