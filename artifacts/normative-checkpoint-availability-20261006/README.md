- [LegalIR384 — four containers](https://huggingface.co/Publicus/legal-ir-autoencoder-384d/tree/8199354f58af914768c2296c441ccda2f8e39daa/releases/20261006-normative-wording-checkpoints-v1).
- [LegalIR768 — four containers](https://huggingface.co/Publicus/legal-ir-autoencoder-768d/tree/1cc315894142c9d3b05c6fff90556cde7a2578fe/releases/20261006-normative-wording-checkpoints-v1).

The task is `semantic_IR_reconstruction` and the dimension role is
`input_embedding`. Original 512-token context/output budgets and width-specific
native paragraph/clause/mask inputs are preserved. Existing saved embeddings
were reused: no training, encoder run or new embedding generation took place
in this availability work. Immediate continuation parents and original donor
lineage remain distinct. The retained 8D lane and other IR-family inventories
are unchanged; these new files are LegalIR 384D/768D assets only.

The release contains private-format JSON state containers and vector-free
preprocessing metadata. It is not a Transformers AutoModel bundle, complete
portable runtime closure or optimizer-resume release. It does not publish raw
corpus text, embedding caches or the complete ModelManager database. Existing
root model cards/defaults remain untouched.
