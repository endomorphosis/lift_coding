# Reading the audit ledgers

`studies.json` groups evidence by the original report identity. `runs.jsonl` uses a unique `ledger_id` for each retained run/event/case/control or explicitly unbound observation. `original_run_id=null` is an unknown identity, never a shared key. The 32-cell and 24-cell historical aggregate populations are represented in studies, not synthesized as invented individual trial rows.

Every normalized run retains its workstream's `source_observation` with the full allowlisted projection. The normalized columns aid comparison; they do not erase original field semantics, nested clock scopes, participation evidence or limitations. `tokens` retains the strict/selected counter projection; `reported_tokens` additionally preserves reported incomplete totals. `native_usage_complete` and `whole_pipeline_usage_complete` are separate. Reward, supervisor completion, accepted node, publication and usage completeness are separate outcomes.

`sessions.jsonl` has two explicit identity kinds. A provider session can carry a final cumulative counter. A retained provider-call ID without a conversation ID is not promoted to a session, and its event's total is not divided among its calls. The 62 rows comprise these different kinds; no combined total is emitted. Shared-control relationships are explicit graph edges, and the same native T2 control is represented once.

Three incompatible accounting schemas are preserved: Codex input includes cache and output includes reasoning; historical direct-Grok input plus visible output plus reasoning uses disjoint reasoning, with cache inside input; Grok CLI X1 uses disjoint fresh-input/cache/cache-write/output categories. A provider name alone cannot select one schema. Missing all-attempt observations stay incomplete, even for passing tasks.

`artifacts.jsonl` is the private fresh-read/hash inventory. Its `role` distinguishes current sources/documents from original receipts where explicitly classified; claim/run rows retain the evidence tier. An artifact can support different claims at different tiers. SHA256 equality is a byte binding, not a signature, source truth, loaded-module proof or experiment rerun. `report_commit_manifest.json` separately records path history and matching current Git blobs; tracked dirty content has no asserted report-content commit. Untracked retained artifacts need not have a report commit. Reporting snapshots/current heads are never substituted for executed forests.

`cross_ir_trace.jsonl` contains five domain rows per retained Terminal-Bench row. “Actually invoked” can mean an advisor ran and failed open; inspect the stage outcome before interpreting it as learned inference. Source preparation or prediction does not establish an admitted Intent→Codebase correspondence. Missing Legal/UI applicability is not an explicit inapplicable-domain decision. Counterexample and action-stage observations stay separate, and no full joined chain is asserted. Current implementation source inspection has its own matrix.

`encoder_deployment_ledger.jsonl` preserves separate heads, local learner descriptors and standalone development training. Reported weight/checkpoint commitments are distinct from freshly read bytes. No checkpoint is qualified because it loaded, trained, reconstructed an authored target or appeared in an index. Runtime consumption, holdout qualification, grammar coverage and authority require their own evidence.

The exception inventory is exhaustive over the bounded normalized rows, not the entire project. Aggregate-only populations and pre-invocation configuration failures are separately described. Exact unrecovered fields and bounded search routes remain in the workstream findings and `missing_evidence.md`. Absence from this inventory does not prove an event did not occur.
