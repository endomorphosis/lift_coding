# Retained legal autoformalization work

This archive preserves authored source, tests, candidate patches, and qualification records from project worktrees and temporary workspaces. The manifest records the original file, SHA-256, byte count, and disposition. A reference to the previous archive means the matching bytes were already published there.

The datasets submodule advances the two-file V2 governing-definition fix. Its exact tested files were carried forward onto the latest main. The retained local qualification records 15 V2 and 14 V3 fixture cases and 135 matching source file identities.

Files under this directory are historical or in-progress evidence. The two bundles preserve isolated branch identities and have been restored against their recorded public parent commits. The historical worktree files are separate byte-exact captured variants, with their own manifest. Records of private tests, refused setups, and inert execution controls retain their original scope. Raw runtime and model artifacts, credentials, and transient caches stay outside this archive.
