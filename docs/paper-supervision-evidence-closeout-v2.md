## Publication status and limitations

This is an **identified author evidence archive**, not an anonymous workshop supplement. It retains paths, task identifiers, timestamps, hashes and provenance. A bounded publication review found no credential literals, private keys, hidden/reference source bodies or raw model transcripts in the exported bundle; this is not an exhaustive secrecy or anonymity guarantee. File commitments do not include the underlying runtime archive, checkpoint weights or complete original logs. Existing attribution and license notices are retained.

Statements in the frozen files such as `publication_authorized: false`, `uploaded: false`, and “private author material” describe their status when created. The subsequent explicit instruction to push this work authorizes this repository publication. Those historical records are preserved without alteration. No original signatures are claimed for derivatives.

Publication does not apply the proposed manuscript patches, submit the supervisor objective, qualify an unsupported decoder or checkpoint, resolve the missing revision-package identity, or establish the complete cross-IR execution path. No benchmark, model, training, solver, grader or production-service execution was performed for this publication. The local disk-capacity issue remains unchanged.
