# Autoencoder evaluation: methods and scope

The repaired experiment evaluates the retained learned models, rather than retraining until a desired held-out result appears. AF-029 trained three seeds (104729, 130363, 155921) on 69 CFR records, with 15 CFR selection records. Each T2 checkpoint contains learned embedding projection tables. Its modal and LegalIR view logit tables are empty: fixed-vocabulary classification is therefore an untrained control, not a learned guidance result. T3 retains the same decoder parameters and adds isolated proof-advisory heads.

The source encoder is the actual cached `sentence-transformers/all-MiniLM-L6-v2`, revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`. Full texts are tokenized without truncation into 254-content-token windows. Attention-mask mean pooling and per-window L2 normalization precede a content-token-weighted document average and a final L2 normalization. A new offline CPU execution reproduced all 15 retained selection vectors bit for bit. The model is loaded by a bounded process and exits after its batch; it runs no inference service.

The native modal parser receives the same 4,096-character source prefix used in training. Its source-only feature computation is separate from scoring. The decoder receives the source embedding as its input, uses actual learned float64 parameters, and emits its fixed direct projection before the scorer reads reconstruction targets. The output alphabet is frozen from the training checkpoints as `deontic.ir` and `knowledge_graphs.neo4j_compat`. It never derives candidate output labels from a scored example's target. Sample memory is disabled for T0, T2, and T3, and reference caches remain empty.

This boundary repairs an important defect in the historical diagnostic evaluator. The native `_reconstruction_safe_projection` chooses a point using the reconstruction target and can return the target itself. Consequently, a high historical reconstruction cosine can be trivial. The repaired decoder returns the unselected learned candidate directly. Reconstruction of a source-derived embedding remains a diagnostic: the architecture retains a linear path from its 384-dimensional input embedding, so these results do not demonstrate a compressed semantic bottleneck, legal fidelity, natural-language recovery, or theorem correctness. An identity-copy control would have cosine 1 and MSE 0 by construction.

T0 is the native cold projection. T1 is the actual retained memorization baseline: each model contains 69 source-keyed training memories. The evaluator computes native sample identities and performs every memory lookup. On a miss, it verifies the native cold projection is exactly equal to the retained T0 result; all 13 shared decoder component scales remain zero, as in the original T1 experiment. It reports hits and misses explicitly and does not relabel T0 classifier outputs as fresh T1 measurements.

T3's decoder is tied exactly to the matching T2 state. Fresh hashes of all six original 5.879 GB checkpoint files match the retained training manifest. The paired protected fingerprints and every extracted non-proof parameter field agree. T3's source-embedding column therefore reuses the corresponding T2 outputs, with **zero additional decoder calls** and no claim of an independent replicate. Its actual native proof heads are evaluated separately for all seven fixed family contexts. These heads are learned contextual or global priors; single-label distributions do not establish confidence in proof truth. A development execution showed the derived T3 vectors and proof-head outputs were bit-for-bit equal to an actual native T3 run on all 15 selection records.

For uncertainty, the primary paired bootstrap follows the original AF-004 source-component grouping (10,000 draws, seed 104729). The dominant source component and four-edition dependence must remain visible. A 2,000-draw domain-stratified unit bootstrap is only a secondary conditional cohort display. The three training seeds are averaged within each source unit before paired resampling; they are not three independent copies of the evaluation corpus.

The extraction converted large JSON vector tables into exact float64, read-only arrays one checkpoint at a time. It preserved original checkpoint hashes, row keys, component identities, and native JSON-float equivalence checks. These arrays contain learned weights, not source-example memory. Final inference verifies compact checkpoint hashes, vector manifests and every vector/key file, source embedding identities, and the frozen native implementation before producing predictions.

## Development history retained

An initial seven-view pilot and an incorrect proposed two-view alphabet were retained as development artifacts. A boundary test rejected the latter because it did not match the actual training checkpoint keys. The final alphabet was read and asserted from all three training states before any final-source access. No candidate was selected by held-out outcomes. The corrected selection result for seed 104729 was mean cosine 0.598898 and MSE 0.001769, compared with the cold/memory-miss baseline 0.196116 and 0.002527. These are selection measurements, not the final results.

## Execution-only source activation cache

Before any final AE predictions were generated, the execution plan was amended to prepare source activations once per record and share them across T0 and the three T2 decoders. The scientific consumer and learned parameters remain unchanged. The preparation model has no accessible learned state: every attribute read from its state object raises an error. Both reference caches are empty, and no feature codec is attached. All other native initialization settings are checked for equality across the four models. Each decoder receives its own deep copy of the resulting cache and still executes the frozen `predict_row` function. The per-record cache is discarded after the four predictions.

The qualification compares every non-timing output field against a fresh uncached prediction for all 15 selection records and each of the four models. Final receipts retain raw source, input embedding, native feature implementation, and activation hashes. Shared source preparation and joint CPU costs are reported separately from each decoder's measured execution time, because charging the shared work to every arm would count it repeatedly. No final output is selected or repaired using scoring targets.

The final execution partitions the frozen cohort by original row index modulo two. Each bounded worker retains the same four-model, per-record computation, and the collector requires complete disjoint coverage in the original source order. Worker receipts preserve native/model/source/embedding identities; merged receipts bind the combined activation file. Partitioned selection qualification checks all 60 model-record comparisons against uncached execution. Worker CPU costs sum to joint computation; elapsed worker times remain separate.

A supplemental constant training-mean baseline was frozen before any final AE prediction or outcome scoring. It sorts the 69 retained training vectors by record ID, takes their unweighted arithmetic mean, and applies one L2 normalization. It predicts that identical vector for every final source. This descriptive control assesses whether learned reconstruction improves over a constant domain mean; it does not replace the prespecified T2-versus-T0 primary comparison or add a new trained arm.

## Observed resource conditions

Final vector encoding completed in a temporary offline CPU process: 1,913 documents, 19,955 windows, and 4,819,558 WordPiece tokens. It used 1,700.37 wall seconds, 1,656.61 process-CPU seconds, and about 1.006 GB peak RSS. The process exited after producing its complete receipt.

The final decoder partitions initially used logical CPUs 14–15 and 16–17, with an 8 GiB address-space bound per worker. Other active workloads shared the host, including processes without restricted affinity. At approximately nine minutes, each decoder worker had accumulated only about 0.65–0.66 CPU seconds per wall second. These conditions make observed latency descriptive; no exclusive-core or controlled-throughput claim is made. A separately recorded, parent-authorized affinity-only amendment moved all three existing threads of worker 0 to CPUs 14 and 19 without changing thread counts, parameters, arithmetic, input, output, or its original deadline. The worker's frozen receipt reports its initial assignment; `affinity_amendment_worker0*.json` records the live change.

A null-only metadata adapter supplies the supplemental constant-mean scorer's required `seed` and `wall_seconds` fields. It retains the frozen producer's raw predictions and verifies equality of every original field, including all vector coordinates. The frozen producer and scorer remain unchanged; the amendment and independent review distinguish this schema repair from inference or a statistical change.

A subsequent capacity audit corrected the initial topology interpretation: repeated `lscpu` core identifiers did not establish SMT, while sysfs sibling lists were singleton. CPU 14 reported capacity 731 and a 2.808 GHz maximum; CPUs 18 and 19 reported capacities 1017 and 1024 with 3.9 GHz maxima. Worker 0's three existing threads were therefore moved again, to CPUs 18–19. Worker 1 retained CPUs 16–17. The separate `affinity_amendment_worker0_fast.json` and applied receipt document this change. It retains the two-logical-CPU bound and makes no host-isolation or throughput claim.
