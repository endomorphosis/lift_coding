# Run IP Analyzer (GraphQL) to check an IP risk score via AbuseIPDB

## Background
IP Analyzer unifies information about public IP addresses into a simplified GraphQL schema. It uses well-known IP scanners; currently, AbuseIPDB is the only scanner mentioned.

## Use Cases
- Provide a single GraphQL API to query risk information for a public IP address.
- Run the project locally for development and testing.
- Use the hosted GraphQL endpoint to integrate IP risk lookups into internal tools.

## Inputs
- A public IP address to analyze.
- Node.js 16.x.
- Yarn or npm.
- Source repository: <URL>

## Outputs
- A running GraphQL server (local dev) for IP analysis.
- Test results from the project’s automated test suite.

## Steps
1. Install Node.js 16.x.
2. Install Yarn (or ensure npm is available).
3. Clone the repository:
   - `git clone <URL>
   - `cd ip-analyzer`
4. Install client dependencies:
   - `yarn install:client`
5. Install server dependencies:
   - `yarn install:server`
6. Start the client in development mode:
   - `yarn dev:client`
7. Start the server in development mode:
   - `yarn dev:server`
8. Open the hosted frontend (optional) to explore the schema/UI:
   - <URL>
9. Open the hosted GraphQL endpoint (optional) for direct API interaction:
   - <URL>
10. Run automated tests:
   - `yarn test`

## Verification
Run a basic network-level check that the hosted GraphQL endpoint is reachable and responds with HTTP 200.

```bash
set -euo pipefail

# Expected outcome:
# - Prints an HTTP status code
# - Status should be 200 when the endpoint is up

url="https://ip-analyzer-server.vercel.app/graphql"
status=$(curl -sS -o /dev/null -w "%{http_code}" "$url")
echo "HTTP status: $status"

# Expect: HTTP status: 200
```

## Safety
- Only analyze public IP addresses you are authorized to assess.
- Treat IP reputation/risk results as advisory signals; avoid taking automated disruptive actions solely from a single data source.
- When running locally, avoid exposing the dev server publicly unless you have authentication, rate limiting, and logging in place.
