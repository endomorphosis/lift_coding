# JWT auth, verification, binding, password hashing, and expiry in Go with supanadit/jwt-go

## Background
This skill shows how to use the Go library `github.com/supanadit/jwt-go` to:
- Set a JWT secret
- Generate and verify JWTs from either the library’s default `Authorization` model or your own struct
- Verify and bind (decode) a JWT back into a struct
- Hash and verify passwords using bcrypt (one-way hashing)
- Configure JWT expiry duration

## Use Cases
- Issue JWTs after a successful login.
- Validate incoming JWTs for protected endpoints.
- Decode JWT claims into a typed struct for application use.
- Hash user passwords for storage and verify user login attempts.
- Configure a short-lived token for testing or security hardening.

## Inputs
- Go module dependency: `github.com/supanadit/jwt-go`
- JWT secret string (set via `jwt.SetJWTSecretCode(...)`)
- Credentials/auth payload (either `jwt.Authorization` or a custom struct)
- Token string to verify/bind
- Password string to hash and later verify

## Outputs
- JWT token string
- Boolean validity result from token verification
- Decoded/bound struct data (when using verify-and-bind)
- Hashed password string
- Boolean validity result from password verification

## Steps
1. Create a new Go workspace directory and initialize a module:
   - `mkdir jwt-skill && cd jwt-skill && go mod init example.com/jwt-skill`
2. Create `main.go` that sets a JWT secret code using `jwt.SetJWTSecretCode("...")`.
3. Generate and verify a token using the library default model `jwt.Authorization` and its methods `GenerateJWT()` and `VerifyJWT(token)`.
4. Define a custom struct (e.g., `type Login struct { Email, Password, Name string }`) to represent your auth payload.
5. Generate a JWT from your custom struct with `jwt.GenerateJWT(auth)`.
6. Verify and decode (bind) the JWT into a struct instance with `jwt.VerifyAndBindingJWT(&dst, token)`.
7. (Optional) If you only need validation and not decoding, use `jwt.VerifyJWT(token)`.
8. Hash a password for storage using `jwt.EncryptPassword(plain)`.
9. Verify a login attempt using `jwt.VerifyPassword(hashed, plain)`.
10. Set token expiry duration using `jwt.SetExpiredTime(hour, minute, second)`.
11. Run the program to print a token, validation status, decoded struct data, and password verification status.

```bash
set -euo pipefail

rm -rf jwt-skill
mkdir jwt-skill
cd jwt-skill

go mod init example.com/jwt-skill

cat > main.go <<'GO'
package main

import (
	"fmt"
	"log"

	jwt "github.com/supanadit/jwt-go"
)

type Login struct {
	Email    string
	Password string
	Name     string
}

func main() {
	// Important: set your own secret (default secret is not secure)
	jwt.SetJWTSecretCode("Your Secret Code")

	// Default authorization model
	auth := jwt.Authorization{Username: "admin", Password: "admin"}
	token1, err := auth.GenerateJWT()
	if err != nil {
		log.Fatal(err)
	}
	valid1, err := auth.VerifyJWT(token1)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("default_model_valid=", valid1) // expected: true

	// Custom struct model
	custom := Login{Email: "asd@asd.com", Password: "asd", Name: "asd"}
	token2, err := jwt.GenerateJWT(custom)
	if err != nil {
		log.Fatal(err)
	}

	var decoded Login
	valid2, err := jwt.VerifyAndBindingJWT(&decoded, token2)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("custom_model_valid=", valid2) // expected: true
	fmt.Printf("decoded_email=%s decoded_name=%s\n", decoded.Email, decoded.Name) // expected: matches input

	// Password hashing and verification
	hash, err := jwt.EncryptPassword(custom.Password)
	if err != nil {
		log.Fatal(err)
	}
	pwOK, err := jwt.VerifyPassword(string(hash), custom.Password)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("password_valid=", pwOK) // expected: true

	// Expiry config example (hour, minute, second)
	jwt.SetExpiredTime(0, 0, 1)
	fmt.Println("expiry_configured=1s") // expected: this line prints
}
GO

go mod tidy

go run .
```

Expected outcome:
- Output includes `default_model_valid= true`.
- Output includes `custom_model_valid= true`.
- Output includes decoded fields matching the original custom struct values.
- Output includes `password_valid= true`.

## Safety
- Always set a strong secret via `jwt.SetJWTSecretCode(...)`; relying on any default secret is unsafe.
- bcrypt is a one-way hashing function (not reversible encryption). Store only the hash, never the plaintext password.
- Use short expiry only for testing; in production choose an expiry appropriate for your threat model and user experience.
- Do not log JWTs or password hashes in production logs unless you understand the risk and have controls in place.
