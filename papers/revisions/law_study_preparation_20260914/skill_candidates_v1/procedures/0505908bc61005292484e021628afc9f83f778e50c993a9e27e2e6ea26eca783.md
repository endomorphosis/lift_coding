# Integrate AuthTuna session-based authentication into a FastAPI app

## Background
AuthTuna is a modern async security framework for Python with a FastAPI-first integration and a framework-agnostic core. This skill wires AuthTuna’s database-backed session middleware into a FastAPI service and adds a protected endpoint that returns the current user.

## Use Cases
- Add session middleware to a FastAPI API.
- Protect routes using an authentication dependency that resolves the current user.
- Stand up a local dev instance backed by SQLite.

## Inputs
- Python environment with pip
- A FastAPI application entrypoint (e.g., `main.py`)
- Environment configuration values:
  - `API_BASE_URL`
  - `FERNET_KEYS`
  - `DEFAULT_DATABASE_URI`
  - `SECRET_KEY`

## Outputs
- Running FastAPI service with AuthTuna session middleware enabled
- A `/me` endpoint that returns `{id, username, email}` for the authenticated user

## Steps
1. Create and activate a virtual environment for your project.
2. Install required packages:
   ```bash
   pip install authtuna fastapi uvicorn[standard] asyncpg aiosqlite python-dotenv
   ```
3. Create an environment file (for example, `.env`) with the required configuration:
   ```env
   API_BASE_URL=http://localhost:8000
   FERNET_KEYS=["YOUR_GENERATED_FERNET_KEY","OPTIONAL_OLDER_KEYS_FOR_COMPATIBILITY_DURING_ROTATION"]
   DEFAULT_DATABASE_URI=sqlite+aiosqlite:///./authtuna.db
   SECRET_KEY=your-very-secret-key
   ```
4. Generate a Fernet key and replace `YOUR_GENERATED_FERNET_KEY` in `.env`:
   ```bash
   python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```
5. Create `main.py` and add AuthTuna session middleware plus a protected route:
   ```python
   from fastapi import FastAPI, Depends
   from authtuna.middlewares.session import DatabaseSessionMiddleware
   from authtuna.integrations.fastapi_integration import get_current_user

   app = FastAPI()
   app.add_middleware(DatabaseSessionMiddleware)


   @app.get("/me")
   async def me(user=Depends(get_current_user)):
       return {"id": user.id, "username": user.username, "email": user.email}
   ```
6. Start the development server:
   ```bash
   uvicorn main:app --reload
   ```

Run a basic readiness check that confirms the server is reachable and that `/me` exists.

```bash
python - <<'PY'

assert "/me" in paths, "Missing /me in OpenAPI spec"

print("OK: server reachable")
print("OK: /me endpoint is present")
PY
```

## Safety
- Keep `SECRET_KEY` secret and do not commit it to version control.
- Treat `FERNET_KEYS` as sensitive. Rotating keys may require keeping older keys for compatibility during rotation.
- Avoid using the example values in production; set strong secrets via environment variables or a secrets manager.
