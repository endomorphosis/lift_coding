\section*{E  Pipeline manifest, evaluation protocol, and result fields}
\noindent
One tested combination. Freeze the exact repository commit, loaded module paths, dirty overlays if\linebreak[4]
permitted, domain adapters, schema versions, source artifacts, vocabularies, review profiles, modality\linebreak[4]
profiles, compiler configuration, selected models/tokenizers, and solver/native checker versions. Do\linebreak[4]
not combine one branch's compiler with a different branch's results and call it one tested system.\linebreak[4]
This draft does not inspect unpushed local worktrees.\par

\noindent
Three evaluation populations. Use: (i) controlled minimal pairs with independent expected\linebreak[4]
meanings; (ii) held-out natural documents, code, and traces with source-family/time splits and\linebreak[4]
reviewed entity mappings; and (iii) extracted-media examples only after the concrete extraction route\linebreak[4]
is installed and measured. Separate generator-authored examples from real held-out material. Keep\linebreak[4]
alternative correct formalizations and abstentions instead of forcing a unique string match.\par

\noindent
Annotations and leakage. Freeze the intended propositions, logical profile, exceptions, temporal\linebreak[4]
intervals, ambiguous readings, source-map spans, and admissible assumptions before evaluating\linebreak[4]
model output. Annotators and proof scorers should not use candidate generation as their only oracle.\linebreak[4]
Source derivatives, paraphrases, translations, views, and adjacent sections can leak across splits.\linebreak[4]
Source-withheld realization must block original text, full source maps, file/path recovery, and access\linebreak[4]
to gold IR; it must not quietly retrieve the withheld source.\par
