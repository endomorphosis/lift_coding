\subsection*{K.2  Feature export is not source copying}
\noindent
The stable learned export restricts outputs to reusable feature groups such as compiler contracts,\linebreak[4]
cycle consistency, decompiler surface templates, logic-view contracts, repair lanes and semantic\linebreak[4]
slots. The inspected promotion code explicitly rejects raw-source, source-span, sample-memory, and\linebreak[4]
token-copying markers. It resolves the export against registered contracts and checks fixed-sample\linebreak[4]
paired metrics. Missing guardrail evidence, source-copy regression, symbolic-validity regression or\linebreak[4]
an unfixed sample set blocks guidance emission.\linebreak[4]
The product is a content-addressed guidance record: target contract and family, bounded features,\linebreak[4]
repair suggestions, canary evidence, source-export identity and rollback metadata. Admission of\linebreak[4]
this record is not itself a proof that a specific consumer enabled it. For an end-to-end claim, record\linebreak[4]
the loaded guidance identity and show that the actual compiler or supervisor consumed it under the\linebreak[4]
evaluated configuration. A branch containing training code and a canonical compiler configured with\linebreak[4]
learning disabled are not one measured learned pipeline.\par

\subsection*{K.3  Program synthesis changes the algorithm, not just the weights}
\noindent
Introspection compares predicted and target families/views, decoded and target embeddings, semantic-\linebreak[4]
slot diagnostics, source reconstruction, and feature-group ablations. The TODO mechanism distin-\linebreak[4]
guishes learned-parameter actions from deterministic program-synthesis actions. For example, loss\linebreak[4]
caused by poor shared family ranking can lead to a parameter update; loss caused by an unhandled\linebreak[4]
exception pattern can lead to a parser/realizer patch proposal. Such a patch must be checked against\linebreak[4]
preserved source facets and regression cases before its behavior becomes canonical.\linebreak[4]
The local modal TODO supervisor and the broader external agent supervisor are not assumed identical.\linebreak[4]
The paper's artifact must identify the actual entry point, generated task/proposal, implementation\linebreak[4]
executor, validation record, and activation path used in the experiment. No new autonomous execution\linebreak[4]
is launched by this manuscript.\par

\section*{L  Using IRs together: a concrete explanatory trace}
