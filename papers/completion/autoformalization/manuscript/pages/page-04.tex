\subsection*{4.2  Actual gradient objectives}
\noindent
The packed tensor implementation gathers active rows, constructs predictions, reduces losses in\linebreak[4]
FP32, backpropagates, clips gradients, applies an SGD-style step, and scatters changed rows into\linebreak[4]
transaction-aware state. BF16 activations are optional after a numerical check; the same packed\linebreak[4]
path has a CPU reference. This is real differentiation through tensor losses, not just the word ``SGD''\linebreak[4]
applied to a prose critique loop. The inspected update is not an Adam update. [artifact S26--S28]\linebreak[4]
