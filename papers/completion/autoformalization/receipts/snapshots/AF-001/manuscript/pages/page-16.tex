\section*{F  Source-grounded query procedure}
\noindent
This is a composed method specification, not a claim that one existing function already performs\linebreak[4]
every step.\par

\noindent
1. Bind a query to its source references, target property, ontology, allowed assumptions, and\linebreak[4]
acceptance profile.\linebreak[4]
2. Extract and normalize candidate declarations; retain unresolved observations and possible\linebreak[4]
interpretations.\linebreak[4]
3. Elaborate each formula against its signature; preserve modality, scope, time, exception, and\linebreak[4]
source lineage.\linebreak[4]
4. Resolve cross-source actors, events, resources, and units through admitted bridge records.\linebreak[4]
5. Select only a target view that supports the required constructs. Unsupported loss causes\linebreak[4]
abstention or explicit partial analysis.\linebreak[4]
6. Check compatibility and nonvacuity of the selected premises; create property-preservation\linebreak[4]
obligations for every relied-upon translation.\linebreak[4]
7. Invoke an available solver or prover under exact theory, environment, and resource bounds.\linebreak[4]
Keep candidate, satisfiability, monitor, and kernel-checked outcomes distinct.\linebreak[4]
8. Reconstruct/check evidence at the assurance level required for the query. Bind the actual\linebreak[4]
verified statement to the outer artifact fields.\linebreak[4]
9. Return the conclusion with all assumptions, sources, bridge records, limitations, and result\linebreak[4]
kind. Unknown does not become true or false by default.\linebreak[4]
10. On counterexamples, distinguish a bad source interpretation, an inadequate abstraction, an\linebreak[4]
invalid translation, and a real behavior violation before requesting a repair.\par
