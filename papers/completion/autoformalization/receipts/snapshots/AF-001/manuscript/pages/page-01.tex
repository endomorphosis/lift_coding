\begin{abstract}
\noindent
Autoformalization requires both faithful interpretation and a computational route\linebreak[4]
for reasoning about it. We describe a compiler-guided architecture coupling en-\linebreak[4]
gineered symbolic IRs to adaptive multi-view representation learning. Determin-\linebreak[4]
istic parsers construct source-grounded declarations; decompilers expose source-\linebreak[4]
withheld reconstruction errors; and shared feature, family, semantic-slot, and view\linebreak[4]
parameters are optimized by an implemented packed tensor update and guarded\linebreak[4]
outer selection. BM25, vector indexes, and knowledge-graph traversal supply\linebreak[4]
complementary context rather than truth criteria. A policy-constrained Tactician\linebreak[4]
organizes search, an ITP Hammer translates supported fragments and reconstructs\linebreak[4]
solver candidates, and Leanstral supplies advisory proof-engineering proposals. In-\linebreak[4]
dependently admitted feedback trains isolated proof heads or motivates separately\linebreak[4]
tested compiler/decompiler changes. Stable learned guidance reaches enabled\linebreak[4]
consumers only through source-free, fixed-canary promotion. Shared symbols\linebreak[4]
and explicit preservation contracts connect deontic, temporal, frame, event, graph,\linebreak[4]
Legal, Security, and Intent views without equating their semantics. We distinguish\linebreak[4]
numerical reconstruction from symbolic round trips, and model prediction from\linebreak[4]
checked proof. A synthetic policy--code--trace example and twelve standalone\linebreak[4]
semantic checks illustrate composition. This source-audited methods draft reports\linebreak[4]
no new checkpoint training or end-to-end performance: held-out source fidelity,\linebreak[4]
retrieval benefit, native proof coverage, and total learning/verification cost remain\linebreak[4]
to be measured.\par

\end{abstract}
\section*{1  Introduction}
\noindent
Autoformalization makes heterogeneous material available to mechanical reasoning, but a formula\linebreak[4]
can be well typed and provable while misrepresenting its source. A requirement, implementation, and\linebreak[4]
execution trace also have different truth conditions: an obligation is not an observation, permission\linebreak[4]
is not execution, and belief is not fact. Recent mathematical autoformalization demonstrates useful\linebreak[4]
natural-language translation into formal statements [1, 2, 9]. Our question is how to learn better\linebreak[4]
source-to-symbolic mappings while preserving these distinctions across domains and logical views.\linebreak[4]
The method couples a deterministic semantic pipeline to adaptive representation learning. Compilers\linebreak[4]
create source-grounded intermediate representations (IRs), decomposers expose multiple logical\linebreak[4]
views, and decompilers reconstruct inspectable content. An adaptive modal autoencoder learns\linebreak[4]
reusable feature-to-embedding and feature-to-family/view parameters against these targets. Recon-\linebreak[4]
struction, structural, provenance, grammar, and cross-view diagnostics identify where the symbolic\linebreak[4]
pipeline is inadequate. Bounded optimization then either updates model parameters or proposes a\linebreak[4]
separately validated compiler/decompiler improvement. Checked proof feedback supplies additional,\linebreak[4]
isolated prediction heads rather than rewarding arbitrary changes that make the input easier to prove.\par
