\subsection{Broader impacts}
\label{app:impacts}
A verified mapping from policy or code into a checked artifact can help
reviewers notice missing approvals, missing audits, or inconsistent premises
before deployment. The same machinery can be misused: an incorrect
formalization of a legal or security obligation can be treated as authority;
monitoring queries can be aimed at people rather than at declared system
behavior; and a solver success can be presented as source-faithful proof.
Mitigations retained here are abstention on unsupported fragments, withholding
holdout source bodies, refusing \texttt{sorry}/\texttt{admit} before any
kernel claim, and keeping teacher, reconstruction, and prover success distinct
from independent source fidelity, which remains unmeasured.
