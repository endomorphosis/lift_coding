# Public boundary-evidence component — candidate for review

This off-live component supplies a readable unsigned numerical/structural replay of retained NS020 boundary evidence. It has not been approved as publication-ready. Run `python3 -B reproduce.py` from this directory: the standard-library command verifies member hashes and prints the fixed historical counts and table joins. It runs no tests, native modules, original qualification programs, providers or scorers. No final32 outcomes are included.

The original records and receipts remain privately retained unchanged. `manifest.json` maps each member to original byte digests and explicitly labels exact source/preparation copies versus unsigned scalar derivatives. These mappings are integrity commitments, not public signature authentication. The projection preserves case IDs, Boolean/numerical flags and selected scalar outcome/reason/source identities, while omitting raw command/log bodies, private paths, prompt/code/proof payload fields and unneeded textual context. It never changes false reuse to success or drops failed attempts. All four corrected NS027 invocations stay separate; the v1 NameError and v2 partial cold-launch failure remain failures. Two34-test baseline observations are preparation costs and are not independent repair outcomes.

`EVIDENCE_INDEX.md` defines NS-NNN identifiers. `failure_cases.md`, `boundary_witnesses.json` and `claim_index.json` preserve the reviewed limits, unavailable mechanisms, source presence versus execution distinction and deferred final joins. Recorded count summaries do not turn passing qualification assertions into successful repairs or full boundary guarantees. This component does not reproduce the experimental/native environments, prove the original receipt signatures, or run cold baselines again.

The source directory contains only selected exact historical producer/validator/shim scripts and the v4 corrected NS027 runner. Some original validators invoke native smoke tests; do not run them as the numerical replay. Their relative repository layouts and pinned native dependencies are not recreated here. Earlier NS027 runner bodies are not included, although every invocation’s original source digest and failure remain recorded. `source_index.json` specifies the distinct source/runtime epochs. These are explicit reproduction limits, not evidence that unavailable mechanisms passed.

Original repository and relevant upstream licence notices are retained verbatim under `notices/`. Upstream XMLtodict identity, revision and archive/source digest remain in the scalar baseline records; its source/test archive is not redistributed or executed here. This component creates no new licence claim over upstream code. The new replay source is supplied under the accompanying repository licence.

Prior measured/unknown costs remain under the separate installed prior-cost component; this package does not add or pool them. Unknown aggregate/import/setup costs are not zero. Combine this reviewed component with the separately reviewed prior pilot/cost and actual final32 anonymous components plus eligible source/licence/candidate material to meet NS024; this candidate alone is not the complete paper supplement. No outside human annotation or review is required to run this replay, and none is invented by its results.
