## Method

Sealed-PATH tools `pdfinfo`, `pdffonts`, and `pdftotext -layout` inspected the
release PDF. Shared-template and per-paper style checksums were compared to
the NS-001 recorded inputs. The ZIP namelist and member bytes were scanned
for author-host, email, and Overleaf-project markers. Official
style-generated anonymous text is exempt from the residual-placeholder scan;
unanswered scientific or checklist fields are not.

## Supplement

The ZIP has 468 entries in three unpooled components. No personal email or
`/home/barberb` host path is present. Hits that remain are:

- Anonymized runtime prefixes of the form
  `/anonymous-runtime/operator-root/lift_coding/...` inside four executed
  driver/preparation sources. The username directory was replaced; the
  `lift_coding` path token remains a residual correlation string, not an
  author name or email.
- `overleaf.com` appears only as rejection regular expressions in projection
  and derivative filters.
- `github.com/...` appears in upstream candidate library files
  (charset-normalizer, more-itertools, installer), which are third-party
  sources rather than paper-author identity.

A derived portable provenance index inside the ZIP maps anonymous release
paths to preserved original private hashes. Those mappings are integrity
lineage, not public signature authentication and not author-identity
disclosure.

## Residual limits

`lift_coding` path token can correlate with privately held originals. This
audit does not claim de-identification. Author proofread remains outstanding.
