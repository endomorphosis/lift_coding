# LA-032 generated-code study preparation

This directory freezes the prospective generated-code study. It does not
execute the 900 scientific cells.

`prepare_study.py` verifies source bytes, excludes every LA-004/LA-029 family
and derivative, applies the ranked SHA-256 split with salt
`vericodegen-2026-law-to-action-LA016-v1`, builds 60 source-relative cases,
seals final oracles, and records actual model, program-profile, watchdog,
deadline and driver qualification probes.

`verify_preparation.py` is the read-only readiness verifier. Completion of
LA-032 means readiness only.
