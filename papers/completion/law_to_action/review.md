## Experimental standard and supervisor completion rules

Use the same bounded, licensed source cohorts and sandbox handlers across arms. Report denominators and abstentions, allowed-work success and false denials alongside actual forbidden effects; rejecting everything must not appear successful. Keep fixed-action safety comparisons separate from closed-loop agent comparisons. Cluster uncertainty estimates by source/task family to account for multiple mutations or vulnerable/fixed pairs, and preserve all planned failures/timeouts/unsupported results. Zero observed forbidden effects supports a bounded empirical rate and interval, not a universal safety theorem.

Each executed result needs a command, revision/configuration manifest, environment, seed where applicable, elapsed time, actual exit status, raw case-level records, and explicit fixture/live labels. No task is complete merely because a report file exists. If a dependency is unavailable, record the concrete blocker; do not substitute generated numbers, invented expert labels, cached unrelated results, or silent test skips. Resolve a scoped claim by actual evidence or truthful manuscript removal, while retaining a useful evaluated core.
